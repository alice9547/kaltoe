# 칼퇴 공통 명세 (맥·윈도우 공통)

두 플랫폼의 앱은 이 문서대로 같은 동작·같은 문구를 낸다. 플랫폼별 구현 방법만 다르다.

## 1. 설정

| 키 | 타입 | 기본값 | 뜻 |
|---|---|---|---|
| `mode` | `flexible` \| `fixed` | `flexible` | 출근 방식 |
| `flexible.earliestStart` | `HH:mm` | `09:00` | 이 시각 이후 처음 컴퓨터를 쓴 시각이 출근. 이 시각 전부터 쓰고 있었으면 이 시각 |
| `flexible.workMinutes` | 정수(분) | `540` | 출근부터 퇴근까지(점심 포함). 허용 60~960 |
| `fixed.start` | `HH:mm` | `08:30` | 고정 출근 시각 |
| `fixed.end` | `HH:mm` | `17:30` | 고정 퇴근 시각. `fixed.start` 보다 뒤여야 함 |
| `lunch.enabled` | bool | `false` | 점심 단계 사용 |
| `lunch.start` | `HH:mm` | `11:30` | |
| `lunch.end` | `HH:mm` | `13:00` | `lunch.start` 보다 뒤여야 함 |
| `notify.lunch` | bool | `true` | 점심 시작 알림 (`lunch.enabled` 일 때만) |
| `notify.beforeEnd` | bool | `true` | 퇴근 10분 전 알림 |
| `notify.end` | bool | `true` | 퇴근 정각 알림 |
| `widget.fontSize` | 정수(px) | `12` | 위젯 글자 크기. 허용 8~32 |
| `widget.style` | `terminal` \| `bubble` | `terminal` | 위젯 모양. 터미널 창 / 말풍선(5-2절) |
| `widget.character` | `maltese` \| `orange` \| `photo` | `maltese` | 마스코트 캐릭터. 말티즈 / 주황이 / 실사 말티즈(6-1절, 6-2절) |
| `pay.comprehensive` | bool | `true` | 포괄임금제 여부. 켜면 연장수당을 0원으로 표시 |
| `pay.rateAmount` | 정수(원) 또는 비어 있음 | 비어 있음 | 연장수당 단가. 비어 있으면 최저시급(시간당 10320원, 2026년)으로 계산. 허용 1~10000000 |
| `pay.rateUnit` | `hour` \| `minute` | `hour` | 단가의 단위(시간당 / 분당). `rateAmount` 가 비어 있으면 무시 |

- 잘못된 값(끝이 시작보다 이름 등)은 저장하지 않고 설정 화면에 오류를 보여 준다.
- 설정이 바뀌면 즉시 화면과 알림 예약에 반영한다.
- 모든 시각은 로컬 시간대의 "오늘" 기준이다. 자정을 넘기는 근무는 지원하지 않는다.

## 2. 출근·퇴근 시각

**유동 모드 (`flexible`)**
1. 하루에 출근 기록은 하나. 정해지면 그날은 바뀌지 않는다(아래 "다시 감지" 제외). 날짜별로 저장, 14일 지난 기록은 삭제.
2. 오늘 기록이 없고, 지금 ≥ `earliestStart`, 화면이 잠겨 있지 않으면 → 출근 = max(`earliestStart`, 활성화 시각).
   활성화 시각 = 사용자가 마지막으로 컴퓨터를 쓰기 시작한 시각(잠금 해제·절전 해제·로그온·앱 실행 중 가장 최근).
3. 지금 < `earliestStart` 이면 기록하지 않는다.
4. 화면이 잠긴 동안에는 기록하지 않는다.
5. 날짜가 바뀌면 새 날이다.
6. 사후 복구: 앱이 `earliestStart` 이후에 실행됐고 오늘 기록이 없으면, 시스템 기록에서 `earliestStart`~지금 사이 가장 이른 "사용자 깨움/로그온/부팅" 시각을 찾아 출근으로 한다. 없으면 `earliestStart`. 조회 실패 시 max(`earliestStart`, 앱 실행 시각). 조회가 끝날 때까지 규칙 2 기록은 보류.
7. 퇴근 = 출근 + `workMinutes`.
8. "오늘 출근 다시 감지": 오늘 기록을 지우고 규칙 6부터 다시 수행한다.

**고정 모드 (`fixed`)**
- 출근 = 오늘 `fixed.start`, 퇴근 = 오늘 `fixed.end`. 컴퓨터 사용 여부와 무관하다. 감지·저장·복구를 하지 않는다.
- 지금 < `fixed.start` 이면 출근 전.

## 3. 단계와 스냅샷

스냅샷 필드: `now`, `clockIn?`, `clockOut?`, `lunchStart?`, `lunchEnd?`(점심이 유효할 때만), `phase`, `target?`(지금 세고 있는 목표 시각), `remaining`(target 까지 초, 없으면 0), `remainingToClockOut`(퇴근까지 초, 0 이상), `overtime`(퇴근 후 지난 초), `progress`(0~1, (now−clockIn)/(clockOut−clockIn)).

점심이 "유효"하려면: `lunch.enabled` 이고 `clockIn < lunchEnd` 이고 `lunchStart < clockOut`.

단계 결정(위에서부터 먼저 맞는 것):

| 조건 | phase | target |
|---|---|---|
| 출근 시각 없음(유동: 기록 없음 / 고정: 지금 < 출근) | `waiting` | 고정이면 출근 시각, 유동이면 없음 |
| 지금 ≥ 퇴근 | `done` | 없음 |
| 점심 유효, 지금 < lunchStart | `beforeLunch` | lunchStart |
| 점심 유효, lunchStart ≤ 지금 < lunchEnd | `lunch` | lunchEnd |
| 퇴근까지 ≤ 10분 | `almostDone` | 퇴근 |
| 그 외 | `working` | 퇴근 |

## 4. 문구

시간 표기: 남은 시간 긴 형식 `3h 12m 08s`(1시간 미만 `12m 08s`), 짧은 형식 `3h 12m`(1시간 미만 `12m`, 1분 미만 `42s`). 시각 `HH:mm` 24시간제. 진행률 바는 20칸 `[#####...............] 27%` (progress 기준).

### 위젯 (터미널)

`waiting` — 유동
```
$ whoami
아직 출근 전인 사람
# waiting for first unlock after 09:00...
```
`waiting` — 고정
```
$ whoami
아직 출근 전인 사람
# 출근 08:30 까지 12m
```
`beforeLunch`
```
$ npm install 점심
installing... 42m 08s left
[#####...............] 27%
in 08:30 → out 17:30
# 점심 11:30 · 퇴근까지 5h 42m
```
`lunch`
```
$ sleep 점심
점심 끝까지 18m 08s
[########............] 41%
in 08:30 → out 17:30
# 지금은 밥이 P0 입니다
```
`working`
```
$ sudo 퇴근 --force
Permission denied: 3h 12m 08s left
[############........] 64%
in 09:16 → out 18:16
# <주석>
```
주석(위에서부터 먼저 맞는 것): 점심 미사용이고 지금 12:00~12:59 → `# 점심: 일단 밥부터 먹고 생각하자` / progress<0.25 → `# 아직 컴파일 중...` / <0.50 → `# it works on my machine` / <0.75 → `# 반 넘었다. 나머지는 미래의 내가` / 그 외 → `# 거의 다 왔다. 금요일 배포만 하지 말자`

`almostDone`
```
$ git commit -m "퇴근 준비"
9m 05s left
[###################.] 98%
in 09:16 → out 18:16
# 지금 배포하면 안 됩니다
```
`done`
```
$ exit
Process finished with exit code 0
퇴근하세요! out 18:16
# 야근 중 +0h 12m
```
(야근 줄은 overtime ≥ 60초일 때만)

색: 프롬프트 `$` #28C840, 명령 #F2F2F7, 출력 #C7C7CC, 남은 시간 강조 #F28C5A, 주석 #6E6E73, done 의 첫 출력 줄 #28C840. 배경 #1B1B1F(불투명도 0.94), 상단 바 #2A2A30, 신호등 점 #FF5F57 #FEBC2E #28C840, 제목 `kaltoe — zsh` #8E8E93. 마지막 줄 끝에 깜빡이는 블록 커서.

### 메뉴바(맥) / 트레이 툴팁(윈도우) 한 줄

| phase | 문구 |
|---|---|
| `waiting` | `출근 전` |
| `beforeLunch` | `점심까지 42m` |
| `lunch` | `점심 끝까지 18m` |
| `working`, `almostDone` | `18:16까지 3h 12m` |
| `done` | `퇴근! +12m` (overtime 1분 미만이면 `퇴근!`) |

### 메뉴 (메뉴바/트레이 아이콘)

1. `출근 09:16` (비활성. 없으면 `출근 기록 없음`)
2. `퇴근 18:16` (비활성. 출근 없으면 생략)
3. `점심 11:30–13:00` (비활성. `lunch.enabled` 일 때만)
4. 구분선
5. `위젯 숨기기` / `위젯 보이기`
6. `설정…`
7. `오늘 출근 다시 감지` (유동 모드일 때만)
8. `로그인 시 자동 실행` (체크)
9. 구분선
10. `칼퇴 종료`

### 알림

| 시점 | 조건 | 문구 |
|---|---|---|
| lunchStart | `notify.lunch`, 점심 유효 | `점심 시간입니다 — npm install 점심` |
| 퇴근 10분 전 | `notify.beforeEnd` | `퇴근 10분 전 — 지금 배포하면 안 됩니다` |
| 퇴근 정각 | `notify.end` | `Process finished with exit code 0 — 퇴근하세요` |

이미 지난 시각은 알리지 않는다. 같은 날 같은 알림은 한 번만.

## 5. 설정 화면

창 하나, 제목 `칼퇴 설정`.
- 출근 방식: `유동 (처음 켠 시각)` / `고정 (정해진 시각)` 둘 중 선택
  - 유동: `출근 인정 시작` 시각, `근무 시간` 시간·분
  - 고정: `출근` 시각, `퇴근` 시각
- 점심: 사용 체크, 시작·끝 시각
- 알림: 점심 시작 / 퇴근 10분 전 / 퇴근 정각 체크 3개
- 야근: `포괄임금제` 체크(기본 켜짐), `연장수당 단가` 숫자 입력칸(원, 비워 둘 수 있음. 비어 있을 때 자리표시 글자 `최저시급 10,320`) + 단위 선택 `시간당` / `분당` + 안내 한 줄 `비워 두면 최저시급(시간당 10,320원)으로 계산합니다. 참고용 금액입니다.`
- 위젯 모양: `터미널` / `말풍선` 둘 중 선택
- 캐릭터: `말티즈` / `주황이` / `실사 말티즈` 셋 중 선택
- 글자 크기: 숫자 입력칸(px, 8~32) + 위/아래 버튼(1씩 증감). 범위 밖이거나 숫자가 아니면 오류 표시 후 저장하지 않음
- 로그인 시 자동 실행 체크
- 아래에 미리보기 한 줄: 현재 입력값으로 계산한 `출근 08:30 · 점심 11:30–13:00 · 퇴근 17:30` (유동 모드에서 오늘 기록이 없으면 `출근 —`)
- 값이 유효하면 바꾸는 즉시 저장·반영. 유효하지 않으면 빨간 글씨로 이유를 보여 주고 저장하지 않는다.

## 5-1. 글자 크기 (`widget.fontSize`)

- 비율 = `fontSize / 12`. 12 가 기본 모양(창 약 320×150)이다.
- 위젯 전체가 같은 비율로 커지거나 작아진다: 글자, 줄 간격, 여백, 상단 바, 신호등 점, 창 크기(기본 약 320×150 × 비율).
- 마스코트는 픽셀이 뭉개지지 않도록 "기본 표시 크기 × 비율"에 가장 가까운 정수 배율로 그린다.
- 바꾸는 즉시 반영한다. 창의 왼쪽 위 모서리 위치는 유지하고, 커져서 화면 밖으로 나가면 화면 안으로 밀어 넣는다.
- 메뉴바(맥)·트레이(윈도우)·설정 창·알림의 글자 크기는 바뀌지 않는다.

## 5-2. 말풍선 모양 (`widget.style = bubble`)

터미널 창 없이, 마스코트가 화면에 앉아 있고 그 위에 말풍선 하나가 뜨는 모양(데스크톱 펫).

- 창: 배경 완전 투명, 그림자 없음, 항상 최상단, 아무 데나 잡고 드래그, 위치 저장. 위치는 터미널 모양과 따로 저장한다(모양마다 자기 위치).
- 배치: 마스코트는 오른쪽 아래, 말풍선은 그 왼쪽 위. 말풍선 꼬리가 오른쪽 아래(마스코트 머리 쪽)를 향한다. 전체 크기는 내용에 맞춘다(기본 글자 크기에서 대략 190×120).
- 말풍선: 채움 #FFFFFF, 테두리 2px #2B2B33, 모서리는 픽셀 계단 모양(둥근 사각을 2px 계단으로), 글자 #1B1B1F, 한 줄, 좌우 여백 12px·상하 8px. 글자 크기는 `widget.fontSize + 1`.
- 마스코트: 기본 표시 약 60px(× fontSize/12, 정수 배율). 밝은 배경에서도 흰 강아지가 보이도록 실루엣 바깥에 격자 1칸 두께의 외곽선 #3A3A44 를 그린다(터미널 모양에서는 외곽선 없음). 재생 규칙·클릭 점프는 6절과 같다. dance 의 색종이, sleep 의 z 도 그대로.
- 숨기기: 메뉴의 `위젯 숨기기` 로만(신호등 점이 없다).

말풍선 문구 — 남은 시간은 **분 단위 올림**(예: 176분 01초 → `177분`, 30초 → `1분`):

| phase | 문구 |
|---|---|
| `waiting` (유동) | `출근 전…` |
| `waiting` (고정) | `출근 12분 전` |
| `beforeLunch` | `점심 42분 전` |
| `lunch` | `점심 끝 18분 전` |
| `working` | `퇴근 177분 전` |
| `almostDone` | `퇴근 9분 전!` |
| `done` | `퇴근하세요!` (overtime 1분 이상이면 `퇴근하세요! +12분`, 내림) |

## 5-3. 연장수당 (`pay.*`)

- 야근 분 = `floor(overtime / 60)`. 1분이 찰 때마다 금액이 오른다.
- 단가: `rateAmount` 가 있으면 그 값과 `rateUnit`, 비어 있으면 시간당 10320원.
- 연장수당(원) = 단위가 시간당이면 `floor(야근 분 × 단가 / 60)`, 분당이면 `야근 분 × 단가`. 가산율(1.5배 등)은 곱하지 않는다 — 설정한 단가 그대로.
  예(기본 = 시간당 10320): 1분 → 172원, 12분 → 2,064원, 60분 → 10,320원. 예(분당 300): 12분 → 3,600원. 예(시간당 20000): 12분 → 4,000원.
- 금액 표기는 세 자리 쉼표 + `원`.
- 야근 분이 0이면 수당 관련 문구를 전혀 표시하지 않는다.

`done` 단계에서 야근 분 ≥ 1일 때 문구가 다음으로 바뀐다(4절·5-2절의 해당 줄을 대체):

| 위치 | 포괄임금제 아님 | 포괄임금제 |
|---|---|---|
| 터미널 위젯: `# 야근 중 +0h 12m` 줄은 그대로 두고 그 아래에 한 줄 추가(총 5줄) | `# 연장수당 +2,064원` | `# 포괄이라 0원 (원래 +2,064원)` |
| 말풍선 | `야근 12분 · +2,064원` | `야근 12분 · 0원 (포괄)` |
| 메뉴(퇴근 줄 아래, 비활성 항목 추가) | `연장수당 +2,064원` | `연장수당 0원 (포괄)` |

메뉴바/트레이 한 줄(`퇴근! +12m`)은 그대로다. 터미널 위젯의 금액 부분(`+2,064원`)은 강조색 #F28C5A, 포괄일 때 `0원` 도 강조색.

## 6. 마스코트

하얀 말티즈 강아지 픽셀 캐릭터. 그림 데이터의 원본은 `shared/mascot.json` 하나이고, 생성 스크립트가 플랫폼별 소스(`mac/Sources/Kaltoe/UI/MascotData.swift`, `windows/Kaltoe.App/MascotData.cs`)를 만든다.

데이터 형식: `width`, `height`(픽셀 격자 크기), `palette`(문자 → `#RRGGBB`), `frames`(이름 → 문자열 배열, 한 문자열이 한 줄, `.` 은 투명).
프레임 이름(고정): `idle`, `blink`, `breathe`, `sleep`, `eat1`, `eat2`, `sparkle`, `hop`, `danceL`, `danceR`, `angry1`, `angry2`, `cry1`, `cry2`.

기분(mood)과 재생:

| phase | mood | 프레임 재생 |
|---|---|---|
| `waiting` | `sleep` | `sleep` 고정 + 머리 위로 떠오르는 `z` 글자 |
| `beforeLunch`, `working` | `idle` | `idle`↔`breathe` 0.6초 간격, 4초마다 `blink` 0.15초 |
| `lunch` | `eat` | `eat1`↔`eat2` 0.4초 |
| `almostDone` | `sparkle` | `sparkle`↔`hop` 0.3초 |
| `done`, 야근 분 0 | `dance` | `danceL`↔`danceR` 0.4초 + 주변 색종이 픽셀 |
| `done`, 야근 분 ≥ 1, 포괄임금제 아님 | `angry` | `angry1`↔`angry2` 0.3초 (찌푸린 눈썹, 부들부들, 머리 위 화남 표시). 색종이 없음 |
| `done`, 야근 분 ≥ 1, 포괄임금제 | `cry` | `cry1`↔`cry2` 0.4초 (눈물이 뚝뚝). 색종이 없음 |

마스코트를 클릭하면 한 번 점프한다. 그릴 때 안티에일리어싱 없이 픽셀이 또렷해야 한다.

## 6-1. 캐릭터 선택 (`widget.character`)

- 캐릭터는 둘이다: `maltese`(하얀 말티즈, 원본 `shared/mascot.json`)와 `orange`(주황색 픽셀 캐릭터 "주황이", 원본 `shared/mascot-orange.json`). 두 파일의 형식과 프레임 이름 14개는 같다. 격자 크기는 캐릭터마다 다를 수 있다.
- 생성 스크립트는 말티즈를 `MascotData`, 주황이를 `MascotDataOrange` 로 만든다(멤버 구성 동일: 맥은 `width`/`height`/`palette`/`frames`, 윈도우는 `Width`/`Height`/`Palette`/`Frames`).
- 설정을 바꾸면 즉시 위젯(터미널·말풍선), 맥 메뉴바 아이콘, 윈도우 트레이 아이콘(`tray.ico` / `tray-orange.ico`)이 그 캐릭터로 바뀐다. 기분·재생 규칙·외곽선·클릭 점프는 캐릭터와 무관하게 6절·5-2절 그대로다.
- 앱 파일에 박힌 아이콘은 주황이다(맥 `.app`, 윈도우 `.exe`).
- 맥: 캐릭터가 `maltese` 이면 Finder 의 앱 아이콘도 말티즈로 바꾼다 — `NSWorkspace.shared.setIcon(말티즈 이미지, forFile: Bundle.main.bundlePath)`. `orange` 이면 `setIcon(nil, ...)` 로 사용자 지정 아이콘을 지워 박힌 아이콘(주황이)으로 되돌린다. 앱 시작 때와 캐릭터를 바꿀 때 적용한다. 이미 원하는 상태면 다시 쓰지 않는다(UserDefaults 에 마지막 적용 값 기록). 실패(읽기 전용 위치 등)는 조용히 무시한다. 번들 식별자가 없으면(swift run) 아무것도 하지 않는다. 말티즈 이미지는 번들의 `AppIcon-maltese-1024.png`.
- 윈도우: `.exe` 파일 아이콘은 바꿀 수 없다(주황이 고정).
- 윈도우 설정 창의 창 아이콘은 실행 중에 바꿀 수 있으므로 선택한 캐릭터를 따른다.

## 7. 위젯을 잃어버리지 않게 하는 규칙

위젯이 안 보이는데 다시 꺼낼 방법을 못 찾는 상황을 막는다. 맥·윈도우 공통.

1. **시작하면 항상 보인다.** 앱을 새로 시작하면 저장된 "숨김" 상태와 무관하게 위젯을 보여 준다. 숨김은 그 실행 동안만 유지된다.
2. **실행 중에 다시 실행하면 위젯을 꺼낸다.** 이미 실행 중일 때 앱을 또 실행하면(더블클릭), 새 프로세스는 조용히 끝나고 기존 프로세스가 (a) 위젯을 보이게 하고 (b) 위젯을 주 화면의 기본 위치(오른쪽 위, 여백 16)로 옮긴다. 현재 모양(터미널/말풍선) 기준.
3. **위젯 오른쪽 클릭 = 메뉴.** 위젯(터미널·말풍선 어디든)을 오른쪽 클릭하면 4절의 메뉴와 같은 항목이 뜬다. 메뉴바/트레이를 못 찾아도 설정에 들어갈 수 있어야 한다.
4. **드래그가 끝나면 화면 안으로.** 드래그를 놓은 뒤 위젯이 어느 화면의 작업 영역에도 충분히(가로·세로 48px 이상) 걸쳐 있지 않으면, 가장 가까운 작업 영역 안으로 밀어 넣는다.
5. **숨길 때 알려 준다(윈도우).** 빨간 점이나 메뉴로 위젯을 숨기면 트레이 풍선 알림 한 번: `위젯을 숨겼습니다 — 칼퇴를 다시 실행하면 다시 보입니다`. 앱 실행당 한 번만.
6. **처음 실행 안내(윈도우).** 설정 파일이 없던 첫 실행에서 풍선 알림 한 번: `칼퇴가 실행 중입니다 — 위젯을 오른쪽 클릭하면 설정을 열 수 있어요`.

## 6-2. 실사 캐릭터 (`widget.character = photo`)

픽셀 그림이 아니라 실제 강아지 사진에서 배경을 지운 이미지 한 장을 쓰는 캐릭터.

- 원본: `shared/source/maltese-photo.jpeg`. 배경 제거 결과: `shared/photo-maltese.png`(투명 배경, 긴 변 512px, 강아지 전신이 여백 없이 꽉 차게 잘림).
- 표시: 픽셀 캐릭터와 같은 자리·같은 기준 크기(터미널 약 60, 말풍선 약 60 × fontSize/12). 부드럽게 축소(최근접 아님). 가로세로 비율 유지.
- 외곽선(5-2절)은 그리지 않는다. 대신 말풍선 모양에서는 어두운 배경·밝은 배경 모두에서 보이도록 옅은 그림자(검정 35%, 흐림 3, 아래 1)를 준다.
- 프레임이 한 장뿐이라 기분은 **움직임과 덧그림**으로 표현한다(이미지 자체는 그대로):

| mood | 움직임 | 덧그림 |
|---|---|---|
| `sleep` | 아주 느린 숨(세로 1.00↔1.03, 2초), 불투명도 85% | 머리 위 떠오르는 `z` |
| `idle` | 숨(세로 1.00↔1.02, 1.2초) | 없음 |
| `eat` | 고개 끄덕임(아래로 2px↔0, 0.4초) | 발치에 밥그릇(코드로 그린 단순 도형) |
| `sparkle` | 통통 뜀(위로 4px↔0, 0.3초) | 양옆 노란 반짝이 |
| `dance` | 좌우 기울임(−8°↔+8°, 0.4초) | 색종이 |
| `angry` | 좌우 떨림(±1.5px, 0.08초) | 머리 오른쪽 위 빨간 화남 표시 |
| `cry` | 살짝 처짐(아래로 1px) | 양쪽 눈 아래 하늘색 눈물방울이 떨어짐(0.4초 주기). 눈 위치는 이미지 기준 비율 좌표로 지정 |

- 클릭 점프는 다른 캐릭터와 같다.
- 맥 메뉴바 아이콘: 얼굴 부분을 잘라 낸 컬러 이미지(템플릿 아님, 18pt). 윈도우 트레이: `tray-photo.ico`(16~32px). 윈도우 설정 창 아이콘: `app-photo.ico`.
- 맥 Finder 아이콘: `photo` 를 고르면 `AppIcon-photo-1024.png`(둥근 사각 배경 위에 사진 캐릭터)로 덧씌운다(6-1절의 말티즈와 같은 방식).
